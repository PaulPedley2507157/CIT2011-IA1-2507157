"LLMs such as ChatGPT, Claude, and CoPilot must be used as a tool not a crutch"

As a computer science student using LLM as a tool and not a crutch means using it as a guide rather than allowing it to complete your entire assignment. Using “LLM” as a crutch is when you place a prompt into a “LLM” source and copy the results without knowing how any of what you're being asked works. This would still give you your pass but would be helpless when provided with a similar task without access to “LLM”. Using “LLM” as a tool would be more like a guide rather than it completing the entire assignment. It would simplify your task while you would still be doing most of the problem solving. As recent computing education research points out, generative AI can either act as a valuable scaffold for computational thinking or short-circuit the exact mental struggle required to build real programming intuition (Prather et al., 2023).

When I'm completing assignments, if I'm unsure on what exactly to do I use LLMs to outline the steps in completing the task. This ensures that I'm the one doing the assignment and LLM is only simplifying the assignment. I also use LLMs to assist my studying by allowing it to break down complicated topics. I use tools like claude for assistance in assignments and gemini to assist my studying. After completing a coding assignment I usually place my work in Claude and allow it to review and help me to find errors.

Left unchecked, over-reliance on these models can quietly erode foundational problem-solving skills and introduce subtle security bugs or hallucinated libraries into a codebase (Kasneci et al., 2023)
